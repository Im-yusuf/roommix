# roommix

Real-time audio mixing for a face-to-face translation feature. Two or more
people in the same room each record on their own phone, and every device
hears both voices. This service merges those live streams into one clean
16 kHz mono stream for backend processing.

Work in progress: the library, the WebSocket server and the browser simulator
land in that order. Setup, usage and integration notes follow with them.
